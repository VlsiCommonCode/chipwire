Security

Root of trust, capabilities, and isolation.

Open silicon security is a stack: immutable boot, measured firmware, cryptographic identity, and (optionally) capability hardware — not a single “secure core” checkbox.

OpenTitan is the reference open root of trust: inspectable RTL, a silicon lifecycle, and a software contract for attestation.

Caliptra is a CHIPS Alliance RoT aimed at cloud silicon — useful when the threat model is a datacenter package, not a microcontroller.

CHERI / CHERIoT move isolation into the ISA with capabilities, so spatial safety does not depend only on an MMU.

Ibex shows up as the CPU inside several of these designs. If you are building a secure SoC, start with the RoT and privilege model, then pick the core.
