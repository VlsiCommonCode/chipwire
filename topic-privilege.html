CPU architecture

M, S, and U — the privilege contract.

Linux-capable RISC-V cores are not “more pipeline stages.” They implement a privilege and memory-management contract.

Machine mode (M) owns reset, interrupts at the highest level, and the CSRs that configure the rest of the hart. Firmware and OpenSBI live here.

Supervisor mode (S) is where a kernel expects page tables, timer virtualization, and delegated traps. Skip S-mode and you can still run bare-metal or RTOS on U/M, but not a conventional Linux stack.

User mode (U) is unprivileged application code. Isolation is only as real as the MMU, PMP/ePMP, or capability hardware underneath.

When you pick a core, ask: which privilege levels, which MMU (Sv32/Sv39), and which interrupt controller (CLINT/PLIC/ACLINT/APLIC). That list predicts software bring-up more accurately than DMIPS.
